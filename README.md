## <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Activities/Sparkles.png" alt="Sparkles" width="35" height="35" /> **What is PeerPick?**

**PeerPick** is a hyper-local, highly aesthetic, and secure marketplace designed exclusively for university and college campuses. Say goodbye to the uncertainty and spam of public classifieds! By mandating college email verification (e.g., `.edu` / `.ac.in`), we ensure that every buyer and seller is a verified peer from your very own institution.

* **Database:** MongoDB, Mongoose
* **Authentication:** JWT, Nodemailer (OTP / Email Verification)

## <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Hand%20gestures/Waving%20Hand.png" alt="Waving" width="35" height="35" /> **Getting Started**

### 1. Clone the repository
```bash
git clone https://github.com/peerpick0/PeerPick.git
cd PeerPick
```

### 2. Setup the Backend
```bash
cd backend
npm install
# Configure your .env file with MongoDB & Cloudinary credentials
npm run dev
```

### 3. Setup the Frontend
```bash
cd ../frontend
npm install
# Configure your .env file with VITE_API_URL
npm run dev
```

### 4. Setup the Admin Dashboard
```bash
cd ../admin-frontend
npm install
npm run dev
```
